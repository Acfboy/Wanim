<wanim-scene> web component

Zero-config embedding of manim Python scenes into any web page · ← editor demo

1. Shape scene (autoplay, inline <script type="text/x-python">)

The element emits wanim-done when the scene finishes.

2. MathTex scene (MathJax is downloaded on first use)

3. InteractiveScene (shadow-DOM button bar + external el.next())

The button bar below the canvas is inserted into the shadow root by DomInteractiveHost; drag the slider / edit the number, then press Next (or an external button) to finish the scene.

4. Property / event API (autoplay="false")
